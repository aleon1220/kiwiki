# Storage Objects
## Create Ops
#### Copy directories/files to S3 given bucket excuding .git files

```bash
aws s3 cp /tmp/foo s3://bucket/ --recursive --exclude ".git/*"
```

## Read Ops

#### List objects and sort by `LastModified` field

```bash
DATE=$(date +%Y-%m-%d)
aws s3api list-objects-v2 --bucket "$BUCKET" --query 'Contents[?contains(LastModified, `'"$DATE"'`)]'
```

#### List contents of a bucket and export to a text file

```bash
BUCKET="s3-bucket-name"
aws s3api list-objects-v2 --bucket "$BUCKET" --output text > "$BUCKET-Contents.txt"
```

#### List number of S3 buckes

```bash
printf "\n EC2 server name== $(hostname) \n\n" ; aws s3api list-buckets --color on --output table ; \
printf "\n\t Total number of S3 Bucket objects $(aws s3 ls | wc -l) \n"
```

#### List buckets Simplified

```bash
printf "\n local servername== $(hostname) \n" ; aws s3 ls ; printf "\n Total number of S3 buckets $(aws s3 ls | wc - l) \n\n"
```

#### get total Data is in Each of my Buckets?

```bash
for bucket in $(aws s3api list-buckets --query "Buckets[].Name" --output text); do size=$(aws cloudwatch get-metric-statistics --namespace AWS/S3 --metric-name BucketSizeBytes --dimensions Name=BucketName,Value=$bucket Name=StorageType,Value=StandardStorage --start-time $(date --iso-8601)T00:00 --end-time $(date --iso-8601)T23:59 --period 86400 --statistic Maximum --query 'Datapoints[0].Maximum' --output text); echo $bucket: $(numfmt --to si ${size:-0}); done;
```

#### List buckets Prefer cost dollars per month?

```bash
AWS_PROFILE_USE="name-of-aws-profile"
BUCKET_LIST="$(aws s3api list-buckets --query "Buckets[].Name" --output text --profile $AWS_PROFILE_USE)"

for bucket in $BUCKET_LIST; do size=$(aws cloudwatch get-metric-statistics --namespace AWS/S3 --metric-name BucketSizeBytes --dimensions Name=BucketName,Value=$bucket Name=StorageType,Value=StandardStorage --start-time $(date --iso-8601)T00:00 --end-time $(date --iso-8601)T23:59 --period 86400 --statistic Maximum --profile $AWS_PROFILE_USE --query 'Datapoints[0].Maximum' --output text); echo $bucket: \$$(awk -v s="${size:-0}" 'BEGIN { printf "%.2f", s * .023 / (1024*1024*1024) }'); done;
```
